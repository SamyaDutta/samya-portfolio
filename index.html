Projects

A few things I've shipped

Check out my work on GitHub.

Logistics AI

A decision-intelligence agent for cold-chain logistics — built on LangGraph, it reasons across live fleet telemetry (SQL Server), real-time corridor weather, and Pinecone-indexed compliance SOPs to flag high-risk shipments before they become incidents.

Read-only SQL access via a dedicated semantic view, audit logging of every tool call, and a separate admin review console for compliance oversight.

LangGraphPinecone RAGSQL ServerStreamlit

TripPilot AI

A travel-planning agent built on LangGraph and MCP, with a supervisor node that routes tasks to 5 agents, input guardrails that validate requests before they reach the model, and human-in-the-loop approval before a plan is finalized.

FastAPI backend with a dedicated MCP server for live weather lookups, and thread-based sessions so a plan can be revised and re-approved across multiple turns.

LangGraphFastAPIPostgreSQLMCP

Recruvia

A CrewAI-based recruitment pipeline that takes a natural-language job requirement, searches a ChromaDB candidate store, screens and ranks CVs against the role, and sends interview invites automatically over Gmail.

100-point candidate scoring, ChromaDB similarity search over 8 profile attributes, automated interview invites via Gmail SMTP, an HR chat assistant for follow-up questions, and PDF report generation for the full recruitment run.
